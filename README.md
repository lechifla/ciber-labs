# Laboratorios de Ciberseguridad (ciber-labs)

Repositorio personal dedicado a la gestión de entornos de pruebas, laboratorios prácticos de ciberseguridad, automatización con scripts y despliegues contenerizados.

## Estructura del Repositorio
- docker/: Configuración de contenedores y laboratorios aislados.
- scripts/: Herramientas de automatización y soporte.
- 
otas/: Documentación y apuntes teóricos de los laboratorios.
